# JingleQuest
A Christmas LitRPG for kids ages 8–12. Jingle Quest is a story-driven, turn-based role-playing game with dice-roll skill checks, boss battles, loot, a party, mini-games, and a branching ending. Every enemy can be defeated **or befriended**. Kindness is a real game mechanic, and the best ending is earned by being kind to the villain.
